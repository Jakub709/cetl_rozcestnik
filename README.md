# CETL CARGO – rozcestník

Statická stránka pro Martina Cerala a Jiřího Tlustého: 3 videa, 6 prezentací ke stažení, leták A4 (EN/CZ) a odkaz na nový web. Připravil Jakub Solnička (KURZY ELANDIO s.r.o.).

- `index.html` – stránka
- `ke-stazeni/prezentace/` – `puvodni_obsah_*` = přesně podle původní prezentace + dodatku, `volne_zpracovani_*` = volnější zpracování
- `ke-stazeni/video/` – spot 60 s, spot 41 s, intro 14 s
- `ke-stazeni/letak/` – one-pager A4 EN + CZ
- `web/` – zatím kopie konceptu nového webu; odkaz u `id="web-link"` v `index.html` přepsat na URL webu na Netlify
- `netlify.toml` – publikuje se kořen repozitáře, žádný build
